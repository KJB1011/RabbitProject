# RabbitProject

2D 액션 탄막 보스러쉬 게임 · Unity / C# · 1인 개발

[Rabbit & Steel](https://store.steampowered.com/app/2126090/Rabbit_and_Steel/)을 참고해 제작한 개인 포트폴리오 프로젝트입니다. 캐릭터에게 다양한 추가 효과를 부여하는 **아티팩트 시스템**을 중심으로, 확장 가능한 구조 설계와 실제 유저 피드백 기반 개선 과정을 담았습니다.

## 핵심 시스템: 아티팩트(Artifact) 시스템

캐릭터에게 필살기 데미지 증가, 평타 시 추가 공격 발생 등 서로 다른 효과를 부여하는 시스템입니다. 아티팩트 종류가 늘어날수록 조합 가능한 경우의 수도 함께 늘어나기 때문에, **새로운 아티팩트를 추가해도 기존 코드를 건드리지 않도록** 설계하는 것이 핵심 과제였습니다.

- 각 아티팩트를 `ScriptableObject` 기반의 독립적인 데이터 단위로 설계
- 캐릭터의 공격·스킬 이벤트에 반응하는 구조로 구현해, 효과 간 충돌 없이 자유롭게 조합되도록 처리
- 새 아티팩트 추가 시 기존 클래스를 상속받아 필요한 부분만 재정의하면 되는 구조

```
ArtifactBase(SO) ← 개별 Artifact들이 상속
→ CombatEventBus가 공격/스킬 이벤트를 브로드캐스트
→ 각 Artifact가 자신에게 해당하는 이벤트(공격, 회피, 필살기 등)만 구독해 효과 적용
```

## 유저 테스트 기반 개선

itch.io에 배포해 지인들에게 플레이 테스트를 받았습니다. 게임성 자체에 대한 반응은 좋았지만 일부 보스 구간에서 난이도가 높아 어려움을 겪는 유저가 있었고, 이 피드백을 반영해 **사망 시 스테이지 처음이 아닌 해당 구간에서 재시작할 수 있는 중간 세이브 기능**을 추가로 구현했습니다.
